使用帮助

什么是本体论？

本体论是对概念和关系的形式化描述，帮助你构建知识图谱，发现笔记中的逻辑结构。

使用步骤

  1. 在设置中配置你的 API Key
  2. 粘贴你的笔记或文本到左侧输入框
  3. 点击"提取知识图谱"按钮
  4. AI 会自动分析概念和它们之间的关系
  5. 在右侧查看生成的知识图谱

图谱操作

  • • 拖拽节点可以移动位置
  • • 滚轮可以缩放图谱
  • • 点击节点查看详细信息
  • • 点击连线查看关系类型
